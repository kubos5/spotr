# Bundled title fonts

These FIGlet / TOIlet fonts are embedded in Spotr for the ASCII-art titles.
Each file keeps its original header and comments; licenses below.

| File | Font | Author | License |
| --- | --- | --- | --- |
| `ansi-compact.flf` | ANSI Compact | Loïc Cressot | MIT (stated in the font header) |
| `future.tlf` | Future | Sam Hocevar (TOIlet) | WTFPL v2 |
| `pagga.tlf` | Pagga | Sam Hocevar and pagga (TOIlet) | WTFPL v2 |
| `emboss.tlf` | Emboss | Sam Hocevar (TOIlet) | WTFPL v2 |
| `small-block.tlf` | Small Block | Sam Hocevar (TOIlet) | WTFPL v2 |
| `small-braille.tlf` | Small Braille | Sam Hocevar (TOIlet) | WTFPL v2 |
| `mini.flf` | Mini | Glenn Chappell (FIGlet) | FIGlet font license: free to modify and redistribute as long as modifications are credited in the font's comments |

The fonts were obtained from <https://patorjk.com/software/taag/>.

You can add your own fonts without rebuilding: put `.flf` or `.tlf` files in
the `fonts` folder next to Spotr's config file (`spotr --print-paths`).
